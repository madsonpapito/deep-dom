## Recommended Free Video/Audio Libraries 

- `moviepy` (Python) - Perfect for basic editing, combining clips, adding audio, and applying transitions.
- `ffmpeg-python` (Python) - Pythonic wrapper for FFmpeg commands to slice, trim, and render fast.
- `pydub` (Python) - For precise audio manipulation, silence trimming, and background music volume adjustments.
- `whisper` (OpenAI Python) - For automatically transcribing the narrated audio to generate subtitles/captions.
- `ImageMagick` - Often used alongside moviepy for generating complex text overlays.

## Quick Commands

- `*help` - Show all available commands with descriptions
- `*generate-vsl` - Start the script to assemble a VSL from a folder of assets
- `*extract-audio` - Quickly extract mp3 from mp4 using FFmpeg
- `*sync-subtitles` - Generate SRT files and burn them into the video
- `*apply-transitions` - Add fade in/out or crossfade between multiple video parts
- `*optimize-web` - Compress video for fast web delivery (H.264/AAC for Vercel/HTML5 players)
- `*guide` - Show comprehensive usage guide for this agent
- `*yolo` - Toggle permission mode
- `*exit` - Exit agent mode
